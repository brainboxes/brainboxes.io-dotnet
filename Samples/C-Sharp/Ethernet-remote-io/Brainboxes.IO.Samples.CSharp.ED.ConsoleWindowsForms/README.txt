This is the C# example/library code package for communication with with 
Brainboxes Ethernet-attached data acquisition and control products, and is 
provided by Brainboxes Limited.  Examples in other programming languages are 
also available.

This is free and unencumbered software released into the public domain.

The file Visual Studio Solution Brainboxes.IO.Samples compiles to an executable program which demonstrates 
the use of the Brainboxes.IO library, which is defined in the Brainboxes.IO solution.
You can use the Brainboxes.IO library in your own programs, simply add a reference to
Brainboxes.IO in your visual studio project. See the EDConsole program as an example of how it is used.

Exploring the Code
* Best entry point to explore the Brainboxes.IO.Samples code is the EDConsole.cs file

BUILDING/Executing
* Open the Solution in Visual Studio: and choose Debug>Start Debugging to be able 
to set break points and step through the code.
* Install the stand alone installer: in windows Explorer go to Brainboxes.IO.Samples/setup/ run setup.exe
* Create your own installer: Right Click on 'Brainboxes.IO.Samples' in the Solution explorer 
and choose "publish" to create an installer which will allow the program to be installed
in Micorosoft Windows and run from Start>Programs>Brainboxes>Brainboxes ED Console. Note
change installer path in the publish dialog
