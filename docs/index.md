# Brainboxes.IO Documentation

Official .NET API documentation for communication with Brainboxes Ethernet-attached data acquisition and control devices.

## Getting Started

This library is designed for Brainboxes Digital and Analog Remote IO and Ethernet to Serial devices including:

- BB-400
- ED-588, ED-516, ED-527, ED-549, ED-560
- ES-246, ES-257
- And the rest of the Brainboxes ED and ES range

## Supported Platforms

- .NET 10
- .NET Standard 2.0 / 2.1
- .NET Framework 4.8

This package can run on:

- Windows 7, 8, 10, 11
- Windows Server 2008, 2012, 2016, 2019, 2022, 2025
- Windows IoT Core
- Linux, Raspbian, macOS
